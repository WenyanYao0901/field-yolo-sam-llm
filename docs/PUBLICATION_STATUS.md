# Publication and asset status

Last reviewed: 2026-09-23

## What is publicly reusable

- Repository source code and configuration files are released under
  Apache-2.0.
- The diagrams `fig01`, `fig02`, `fig03`, and `fig13` describe the software
  architecture. They may be redistributed with the repository under
  Apache-2.0.
- Images generated locally by `scripts/make_sample_images.py` are synthetic
  smoke-test assets. They are not field observations and must not be cited as
  experimental evidence.

## What is not an open dataset or published result

- The manuscript files in this directory are unpublished working drafts.
  Public repository access does not constitute journal publication or grant a
  separate right to republish the manuscript outside the repository.
- No real field dataset is distributed by this repository.
- No model weights are distributed under this repository's license.
- Placeholder quantitative figures are not experimental results and are being
  removed from the tracked repository.

Before adding a field image or dataset, the contributor must confirm ownership,
participant/privacy clearance where applicable, location metadata removal, and
permission from the university or project sponsor. Record the source, creator,
capture date, consent/clearance basis, and license in a dataset card.
