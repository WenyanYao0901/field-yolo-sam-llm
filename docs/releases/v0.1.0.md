# field-yolo-sam-llm v0.1.0

First formally documented research-prototype release.

## Highlights

- Hard-example-driven YOLO → SAM → LLM pipeline with structured outputs.
- Apache-2.0 source-code license and citation metadata.
- Independent dataset split policy and exact-duplicate leakage checker.
- Eight lightweight unit tests and a reproducible synthetic smoke-test output.
- Removal of unmeasured placeholder figures and duplicated sample data.
- Credential handling guidance and removal of the previously exposed token from
  reachable Git history.

## Research limitations

- No real field dataset or trained field-specific weights are included.
- The included screenshot is a synthetic software smoke test, not a benchmark.
- The manuscript remains an unpublished working draft; all quantitative claims
  require replacement with measured field experiments.
- Any credential exposed before this release must be revoked at its issuing
  provider even though it no longer appears in reachable repository history.

See `CHANGELOG.md`, `SECURITY.md`, and `docs/PUBLICATION_STATUS.md` for details.
